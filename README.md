# Resource Tagged Wiki for Game Data

This Python script demonstrates a simple resource-tagged wiki design for early access game information. It allows adding entries with specific source types and details, enabling organized data management and retrieval.

## Language

`python`

## How to Run

Save the code as `wiki_builder.py` and run it from your terminal using `python wiki_builder.py`. It will create `wiki_data.json`.
